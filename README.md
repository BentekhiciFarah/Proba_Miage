Ce sont quelques TP réalisés dans le cadre du module "Probabiliés" de la L3 MIAGE, le but étant de trouver des solutions à des problèmes de probabilités en adoptant trois méthode différentes : 
- La méthode nalytique : en se basant sur des calculs et des règles de probabilités réalisés en Python.
- La méthode de force brute : se basant sur la modélisation des données sous forme de dataframe, en utilisant des bibliothèques python et par la suite la réalisation de toutes les combinaisons possibles et éliminer celles qui correspondent par calculer (Cas correspondants / cardinal)
- La méthode probabiliste (Monte Carlo) : se basant sur la simulation de l'expérience un très grand nombre de fois ensuite faire la moyenne de toutes les expériences générées.
Les trois méthodes sont censées donner plus ou moins le meme résultat afin de pouvoir le valider.
